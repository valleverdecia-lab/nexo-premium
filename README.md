# Nexo Premium

Configurador espacial 2.5D independiente para explorar productos reales del catálogo Nexo en Sala, Cocina, Garaje y Baño.

## Desarrollo

```bash
npm install
npm run dev
```

El sitio conserva el catálogo y las fotografías reales, pero vive en un repositorio separado del proyecto `nexo`.

## Publicación

El workflow de GitHub Actions construye `dist/` y despliega GitHub Pages en:

`https://valleverdecia-lab.github.io/nexo-premium/`
